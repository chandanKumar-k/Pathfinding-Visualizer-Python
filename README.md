# Pathfinding Visualizer (BFS)

An interactive 2D grid visualization application built with Python and Pygame-CE to demonstrate Breadth-First Search (BFS) pathfinding.

## 🚀 Features
* **Custom Start/End Points**: Left-click to place the start node (Orange) and target node (Turquoise).
* **Obstacle Drawing**: Left-click and drag to draw solid walls (Black) that the algorithm must navigate around.
* **Real-time Traversal**: Watch the algorithm expand outwards (Red/Green) to explore open blocks.
* **Shortest Path Generation**: Highlights the optimal path in Yellow once the target is reached.

## 🛠️ Controls
* **Left-Click**: Place Start Node / Place End Node / Draw Walls
* **Right-Click**: Clear a Node or Wall
* **Spacebar**: Run the Pathfinding Algorithm
* **C Key**: Reset the entire grid
